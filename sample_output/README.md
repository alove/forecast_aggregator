# Sample output

The samples demonstrate export schema 2.0.0 using the legacy combined snapshot bundled in the uploaded repository:

- `example_national_2026-08-12.csv` — 48 long-form national/chamber metric rows.
- `example_state_2026-08-12.csv` — 8,460 long-form House-district and Senate-race metric rows.

They are examples only. Run `./run.sh collect` from the working directory to retrieve current values into the two live CSVs.
